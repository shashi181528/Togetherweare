Dating for the good in all of us. **Find your people. Grow together.**

## Website

GitHub Pages: <https://shashi181528.github.io/Togetherweare/>

## Android app

This project uses Capacitor. Install dependencies and synchronize the Android project with:

```sh
npm install
npm run android:sync
```

To build a debug APK, run `npm run android:apk` with Java 21 and Android SDK installed.

## Supabase

Run `supabase/schema.sql` in the Supabase SQL Editor. Configure the TextBee OTP delivery hook using [`supabase/TEXTBEE_OTP_SETUP.md`](supabase/TEXTBEE_OTP_SETUP.md). Admin portal setup is documented in [`supabase/ADMIN_SETUP.md`](supabase/ADMIN_SETUP.md).
